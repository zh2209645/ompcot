Authentication

Keys are stored locally in ~/.omp/agent/auth.json (chmod 600). Ompcot launched from Finder does not read shell environment variables, so set keys here for them to stick across launches.

LLM providers

Edit ~/.omp/agent/models.yml to add custom providers (Ollama, vLLM, LM Studio, OpenAI-compatible proxies, OpenRouter routing overrides, etc). The file is YAML — JSON works too, since JSON is valid YAML. See the models.yml docs for the full schema. Changes are picked up immediately — no restart needed.

Providers file

Common agent options, editable in place. Changes save automatically and are picked up by the running agent. Secret keys are managed on the Providers page.
